ГАННИБАЛ. ПАРТИТУРА
консольная визуальная новелла (18+)

===========================================================
ЧТО ЭТО
===========================================================
Психологический триллер с романтической линией по мотивам
сериала «Ганнибал». Вы — молодой профайлер ФБР. Дело
«Композитора», три сеанса с доктором Лектором, три финала.

Фан-работа. Не связана с NBC, Томасом Харрисом и
правообладателями. Все изображения и звуки генерируются
кодом; текст оригинальный. Некоммерческий проект.

Содержит: насилие, манипуляции, темы каннибализма,
эротическое напряжение (без графических сцен).
Если вам меньше 18 — не запускайте.

===========================================================
ЗАПУСК
===========================================================
1. Распакуйте архив (если он в архиве).
2. Двойной клик по HannibalVN.exe.
3. Рекомендуется Windows Terminal (Win 11: по умолчанию).
   В старом conhost тоже работает, цвета могут быть проще.
4. Размер окна: минимум 72x28 (текст и портрет подстроятся),
   лучше 120x40. Если текст обрезан — разверните окно
   или уменьшите шрифт терминала.

Первый запуск: 1-2 секунды на генерацию звука (кэш в
C:\Users\Public\HannibalVN_audio). Дальше — мгновенно.

SmartScreen/антивирус: exe не подписан (PyInstaller), поэтому
Windows может показать предупреждение. Это нормально для
самодельных сборок: «Подробнее» → «Выполнить в любом случае».

===========================================================
УПРАВЛЕНИЕ
===========================================================
ENTER / ПРОБЕЛ     далее (или завершить печать строки)
↑ ↓ / W S          выбор варианта
1 2 3              быстрый выбор
TAB                история диалога (↑↓ прокрутка)
ESC                пауза / меню
В меню сохранений: D — удалить слот

Сохранения: 3 слота + автосейв.
Папка: %APPDATA%\HannibalVN\saves
Настройки: %APPDATA%\HannibalVN\settings.json
Крэш-лог: %APPDATA%\HannibalVN\crash.log

===========================================================
НАСТРОЙКИ
===========================================================
Скорость текста, звук, эмбиент, анимации, плёночное зерно,
ASCII-режим (для слабых терминалов), громкость.

===========================================================
СБОРКА ИЗ ИСХОДНИКОВ
===========================================================
Нужен Python 3.10+ (проверено на 3.13) и интернет для
установки PyInstaller.

  powershell -ExecutionPolicy Bypass -File build.ps1

Результат: dist\HannibalVN.exe

Исходники:
  src/engine   — терминальный движок, анимации, звук, сейвы
  src/art      — процедурный пиксель-арт и фоны
  src/story    — текст, развилки, концовки
  tools        — предпросмотр арта, иконка, отладочные дампы
  tests        — 36 тестов (python -m unittest discover -s tests)

Проверка без запуска игры:
  python src\main.py --selftest
  python src\main.py --export-art preview
